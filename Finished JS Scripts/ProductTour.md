# Joule Studio Product Tour

**Intro**
Explore how Joule Studio builds agents, applications, extensions, and workflows grounded in your SAP business context.

---

## Define Your Intent

**Step 1**
Describe a new solution for identifying orders impacted by new tariffs.

**Step 2**
Joule Studio enriches your intent using SAP processes, data, and architecture context.

**Step 3**
Joule Studio asks follow-up questions to connect to the right SAP S/4HANA data and validate your business logic.

**Step 4**
Based on your intent, Joule Studio produces a product requirements document that captures the problem, personas, and user stories.

**Step 5**
Solution architecture is shaped by your SAP landscape and governance rules from the start.

**Step 6**
Ask Joule Studio to adjust and refine the PRD until it fully maps to your business challenge.

---

## Build the Agent

**Step 7**
The PRD is translated into a technical specification with clear implementation instructions for the agent to follow.

**Step 8**
Joule Studio generates code using SAP best practices, creating enterprise-ready agents, workflows, and applications.

**Step 9**
Iterate directly in the web-based editor, or hand off to Claude Code and your preferred IDE like Visual Studio Code without losing context or progress.

---

## Preview the Completed Agent

**Step 10**
To respond to tariff disruptions, Joule Studio built a React + CAP dashboard, n8n workflows, and an AI agent.

**Step 11**
Ask the tariff agent to identify suppliers at risk under the new tariffs, pulling from live SAP S/4HANA data.

**Step 12**
Automated n8n workflows email supply chain teams when an order is flagged for tariff risk.

**Step 13**
A CAP dashboard application surfaces active order disruptions and margin at risk.

---

## Test and Deploy

**Step 14**
Joule Studio generates a test report that checks agent behavior and performance end-to-end.

**Step 15**
If failures happen, Joule Studio pinpoints the bugs and troubleshoots.

**Step 16**
Deploy to SAP-managed runtime that handles lifecycle management, security, and monitoring.

**Step 17**
Push solutions to GitHub for code review and version control.
